# Principles-of-Software-Engineering-Project-Group-1
The repository of the Principles of Software Engineering Group Project of Group 1 Section 14

Financial Tracker with Emergency Fund System
Relevant SDGs : SDG 3 (Good Health and Well-Being)

The finished product can serve as a tool that can be used to track income and expenses of its users. It will also be able to reveal the user as to how their money is used through informative graphs and tables so that the user can make better financial decisions in the future. Users may also opt-in to an Emergency Fund feature where they would be able to set a reminder that notifies the user to set aside a user-set amount for emergency funds. This prototype will be a glimpse as to how such a tool may look like.
